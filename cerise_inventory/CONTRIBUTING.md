# Contribuindo para o Projeto 5G Open RAN

Agradecemos seu interesse em contribuir para o projeto 5G Open RAN! Este guia ajudará você a entender como pode contribuir e quais são os requisitos para garantir um processo de contribuição eficaz e produtivo.

## Como Contribuir

Existem várias maneiras de contribuir com este projeto:

1. **Reportar Bugs**: Se você encontrar algum problema, sinta-se à vontade para reportá-lo.
2. **Sugerir Funcionalidades**: Tem uma ideia que acha que pode melhorar o projeto? Envie suas sugestões.
3. **Corrigir Problemas**: Escolha um problema aberto e ajude a resolvê-lo.
4. **Melhorar a Documentação**: Melhorias na documentação são sempre bem-vindas.

## Reportando Bugs

1. Verifique se o bug já foi reportado.
2. Abra um **issue** descrevendo o problema de forma clara:
   - Inclua passos para reproduzir o bug.
   - Forneça o ambiente onde o bug ocorre (sistema operacional, versões das dependências, etc.).
   - Descreva o comportamento esperado e o comportamento atual.

## Sugestões de Funcionalidades

1. Abra um **issue** com a tag `enhancement`.
2. Descreva a funcionalidade desejada e explique seu valor para o projeto.
3. Se possível, sugira uma abordagem para implementar essa funcionalidade.

## Processo para Pull Requests

Para manter a qualidade do código, siga estas etapas ao enviar um pull request:

1. **Fork** o repositório e crie sua branch:

   ```bash
   git checkout -b minha-nova-funcionalidade
   ```

2. **Faça commit** das suas mudanças:
   - Certifique-se de que o código segue o padrão de estilo do projeto.
   - Inclua descrições claras e concisas dos seus commits.

3. **Execute os Testes**: Se houver testes automatizados, execute-os antes de abrir o pull request:

   ```bash
   python -m unittest
   ```

4. **Abra um Pull Request**:
   - Explique o propósito do pull request.
   - Descreva as mudanças realizadas e como elas afetam o projeto.
   - Se possível, associe o pull request a uma issue aberta.

## Padrões de Código

- Siga as diretrizes do [PEP 8](https://www.python.org/dev/peps/pep-0008/) para o código Python.
- Nomeie variáveis e funções de forma clara e descritiva.
- Documente as funções com docstrings.
- Mantenha os arquivos organizados e utilize uma estrutura de pastas lógica.

## Código de Conduta

Ao contribuir, pedimos que todos os participantes sigam o [Código de Conduta](CODE_OF_CONDUCT.md) do projeto para manter um ambiente colaborativo e respeitoso.

## Agradecimentos

Obrigado por dedicar seu tempo para contribuir para o projeto! Cada contribuição é muito valorizada e nos ajuda a avançar na criação de um sistema Open RAN 5G inovador e funcional.
