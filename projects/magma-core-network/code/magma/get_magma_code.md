# How to Obtain the Magma Core Code

There are two methods to obtain the Magma Core code: from a specific test drive prepared for tests and from the official GitHub repository. Follow the instructions below depending on your preferred method.

## Method 1: Obtain the Code from a Specific Test Drive

If you have access to a test drive that contains the Magma Core code, you can obtain the code as follows:

1. **Access the Test Drive URL**:

Click the followoing link to access the file hosted on Google Drive:
[Download Magma Core from Test Drive](https://drive.google.com/uc?id=19Vn80XCvW4FZCRspA5wV8pGqyjhCo_8y)

2. **Download the Files**:

   * Once the link is opened, you will be able to download the Magma Core files for your test setup.

## Method 2: Obtain the Code from the Official GitHub Repository

The official Magma Core repository is available on GitHub. You can clone it using Git by following the instructions below:

1. **Clone the Magma Core Repository**:

   * Open a terminal window on your local machine.
   * Run the following Git command to clone the official repository:

   ```bash
   git clone https://github.com/magma/magma.git
   ```

2. **Navigate into the Repository**:

   * After cloning the repository, navigate into the `magma` directory:

   ```bash
   cd magma
   ```

3. **Checkout a Specific Version (Optional)**:

   * If you wish to use a specific version of Magma, such as v1.8, run the following command to checkout that version:

   ```bash
   git checkout v1.8
   ```

4. **List All Available Releases**:

   * To view all available releases for the repository, you can list the tags by running the following command:

   ```bash
   git tag -l
   ```

   This will display all the available versions (tags) in the repository.

---

By following these steps, you will be able to obtain the Magma Core code from either the prepared test drive or the official GitHub repository. Choose the method that best fits your needs.
