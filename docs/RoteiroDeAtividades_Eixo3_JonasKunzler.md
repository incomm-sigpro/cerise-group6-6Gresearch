# Projetos em Desenvolvimento - CERISE

Este documento apresenta os projetos atualmente em desenvolvimento no contexto do CERISE (Centro de Excelência em Redes Inteligentes e Serviços Avançados), hospedados no GitHub para acesso compartilhado e ubíquo.

## 📡 5G Gateway

Repositório focado no desenvolvimento de um gateway de comunicação compatível com redes móveis 5G, integrando sensores e módulos de IoT.

- **Pastas principais**: `code`, `debug`
- **Propósito**: Comunicação entre dispositivos e infraestrutura 5G
- **Link**: [5G_Gateway](https://github.com/incomm-sigpro/cerise-group6-6Gresearch/tree/kunzler-branch/projects/5G_Gateway)

## 🌐 Magma Core Network

Projeto de infraestrutura de rede baseado no Magma da Linux Foundation, voltado à simulação e gerenciamento de redes móveis.

- **Pastas principais**: `assets`, `code`, `docs`, `presentations`
- **Propósito**: Integração com a arquitetura do Magma Core e tecnologias não 3GPP
- **Link**: [magma-core-network](https://github.com/incomm-sigpro/cerise-group6-6Gresearch/tree/kunzler-branch/projects/magma-core-network)

## 📶 Mobile Communication Simulator

Simulador de comunicações móveis com foco em testes de algoritmos para redes 5G e 6G.

- **Pastas principais**: `assets`, `bibliography`, `code`, `docs`
- **Propósito**: Estudo e avaliação de algoritmos de estimação, propagação e modulação
- **Link**: [mobile_comm_simulator](https://github.com/incomm-sigpro/cerise-group6-6Gresearch/tree/kunzler-branch/projects/mobile_comm_simulator)

## 🛰️ Unmanned Ground Vehicle Jamming Mitigation

Sistema experimental para avaliação de técnicas de produção/mitigação de interferência (jamming) baseado em veículos terrestres não tripulados.

- **Pastas principais**: `assets`, `bibliography`, `code`, `docs`
- **Propósito**: Exploração de robustez de comunicações em ambientes hostis
- **Link**: [unmanned-ground-vehicle-jamming-device](https://github.com/incomm-sigpro/cerise-group6-6Gresearch/tree/kunzler-branch/projects/unmanned-ground-vehicle-jamming-device)
